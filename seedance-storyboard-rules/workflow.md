## 使用工作流

### 何时调用此 Skill

调用本 Skill 的典型场景：

- 用户要求创作微短剧分镜（无论是否基于 Seedance 2.0）
- 用户要求拆分镜头、规划镜头序列
- 用户要求编写 Seedance 2.0 / 类似 AI 视频模型的提示词
- 用户要求设计电影级 CG 分镜
- 用户要求套用或修改固定分镜模板
- 用户讨论空间连续性、景别衔接、运镜、双层表演等具体技法
- 用户要求审查既有分镜是否符合规则
- **用户明确画幅为 9:16 竖屏短剧、要求短剧节奏紧凑、长对话切反应镜头、设计开场/结尾钩子**（参考第二十六节）

### 如何套用分镜模板生成新分镜

1. **第一步：规定情境分析（新增·首要步骤）**
   - 完成外部规定情境分析（参考第二十节）
   - 完成内部规定情境分析（参考第二十节）
   - 梳理人物关系矩阵与情绪表达方式（参考第二十一节）
   - 这是所有后续步骤的前提，不完成不能进入下一步

2. **第二步：情绪浓度值分析（新增）**
   - 根据规定情境与人物关系，分析每场戏的情绪（参考第二十一节）
   - 为每个情绪节点匹配浓度值百分比（参考第二十二节）
   - 形成情绪浓度变化曲线（起始 → 发展 → 结果）
   - 提取对应的 CDS2.0 微表情提示词

3. **第三步：空间与关系建立**
   - 明确场景空间结构（参考第十三节）
   - 明确人物站位、距离、朝向（参考第四节）
   - 锁定光影与时间（参考第十四节）
   - **为本场次首镜建立空间承接基准**：标注"本镜为场次首镜，建立空间"，书写场景空间结构、起始站位、锚点初始状态（参考第四节"分镜间空间承接"），作为后续所有分镜空间承接的依据

4. **第四步：镜头拆分**
   - 按"一视频一动作/一情绪"原则拆分（参考第二节）
   - 复杂段落按 A/B/C/D 镜拆分
   - 估算每镜时长（2-3s / 3-5s / 5-7s）
   - **若为 9:16 短剧（参考第二十六节）**：单镜时长收紧至 1.5–4s，禁止超过 5s 的静态长镜；A/B/C/D 拆分中 D 镜（情绪落点）不超过 3s；每句重要台词独立成镜；长对话（A 与 B 连续超过 3 句）必须在第 3 句前插入他人反应镜头（近景/特写，景别比对话镜更近一级），并在反应镜中仍书写"空间承接"字段

5. **第五步：分镜三层级设计（新增）**
   - 叙事层：保证剧情信息完整（参考第二十五节）
   - 情绪层：贴合情绪浓度值（参考第二十五节）
   - 镜头衔接层：流畅自然转场（参考第二十五节）

6. **第六步：填写分镜模板**
   - 使用第十七节固定分镜模板
   - 逐项填写：镜号、时长、人物空间、运镜景别、画面动作、细微动作、声场、台词、正/负向提示词
   - **每镜必填"空间承接"字段**（参考第四节"分镜间空间承接"）：完整书写五要素——上一镜结尾状态、本镜起始状态、承接类型、人物站位承接、人物动作承接、空间锚点承接；场次首镜标注"本镜为场次首镜，建立空间"并书写场景空间结构、起始站位、锚点初始状态
   - 严禁用"同上""承接上一镜"等模糊语代替详细描述

7. **第七步：台词处理（新增）**
   - 台词一字不增、不减、不改（参考第二十三节）
   - 匹配情绪语气色彩：语速 + 音强 + 语调 + 情绪色彩（参考第二十三节）
   - 标注重音：在台词后括号标注（参考第十九、二十三节）
   - 确定潜台词：与台词分行区分（参考第八节）

8. **第八步：表演与肢体动作设计**
   - 将情绪拆解为微动作清单（参考第七节）
   - 匹配情绪浓度值的微表情提示词（参考第二十二节）
   - 设计肢体动作：基于情绪浓度与物件绑定（参考第二十四节）
   - 双层人物按"表情在演，眼睛泄密"设计（参考第九节）

9. **第九步：填写正向/负向提示词**
   - 正向提示词：以第一节通用质量基底为基础 + 选定风格提示词 + 本镜具体描述 + 情绪浓度微表情
   - 负向提示词：列出禁止项（文字、字幕、水印、BGM、过曝等）
   - 提示词按剧本顺序逐字咬合，情绪拆分细腻（参考第十九节）

### 如何校验分镜是否符合规则

按以下清单逐项检查：

| 校验维度 | 检查内容 | 对应章节 |
|----------|----------|----------|
| 空间连续性 | 上一镜与下一镜的站位、距离、朝向是否一致 | 第四节 |
| 空间承接 | **每镜是否填写"空间承接"字段；是否完整书写五要素（上一镜结尾状态、本镜起始状态、承接类型、人物站位承接、人物动作承接、空间锚点承接）；场次首镜是否标注"本镜为场次首镜，建立空间"；是否使用模糊语代替详细描述** | 第四节 |
| 焦点统一性 | 每镜是否只有一个视觉核心 | 第三节 |
| 时长合理性 | 时长是否匹配动作复杂度 | 第二节 |
| 景别衔接 | 是否避免连续近景，是否使用视线/动作匹配 | 第五节 |
| 运镜服务性 | 运镜是否服务情绪，是否为炫技 | 第六节 |
| 表演具体性 | 情绪是否拆为微动作，是否使用情绪词 | 第七节 |
| 潜台词设计 | 重要台词是否标注潜台词 | 第八节 |
| 双层表演 | 绿茶/虚伪角色是否同时存在两层情绪 | 第九节 |
| 群像多样 | 群演反应是否多样，群杂是否层层叠加 | 第十节 |
| 手机处理 | 手机是否作为环境元素，是否遮挡主体 | 第十一节 |
| 物件叙事 | 物件是否绑定动作，是否承担剧情功能 | 第十二节 |
| 场景稳定 | 场景元素是否无故消失 | 第十三节 |
| 光影统一 | 光影是否与时间天气统一 | 第十四节 |
| 蒙太奇拆分 | 心理蒙太奇是否拆为快切 | 第十五节 |
| 声音设计 | 是否无 BGM，OS 是否无口型 | 第十六节 |
| 模板完整 | 是否完整填写固定分镜模板所有字段 | 第十七节 |
| 提示词优化 | 情绪表达是否保留、逻辑重音是否标注、潜台词是否与台词分行区分、提示词是否按剧本顺序咬合、台词是否一字不改 | 第十九节 |
| 规定情境分析 | 是否完成外部 + 内部规定情境分析 | 第二十节 |
| 人物关系情绪 | 是否梳理人物关系矩阵，是否分析不同对象的不同情绪表达 | 第二十一节 |
| 情绪浓度值 | 是否标注浓度百分比，是否形成浓度曲线，是否匹配微表情提示词 | 第二十二节 |
| 台词处理 | 台词是否一字不改，是否标注情绪语气色彩，是否标注重音 | 第二十三节 |
| 肢体动作 | 肢体动作是否匹配情绪浓度，是否与物件绑定 | 第二十四节 |
| 分镜三层级 | 叙事层是否完整、情绪层是否贴合、衔接层是否流畅 | 第二十五节 |
| 短剧节奏 | 单镜是否超过 5s（除非情绪定格收尾）；A/B/C/D 中 D 镜是否 ≤3s；前 3 秒是否有钩子；段落内是否每 15–30 秒一个小钩子；结尾是否留大钩子 | 第二十六节 |
| 长对话反应镜头 | 连续对话是否超过 3 句未切反应；反应镜头景别是否比对话镜更近一级；是否避免同景别同机位跳切；反应镜头是否书写"空间承接"字段；群像对话是否每 2–3 句切围观反应 | 第二十六节 |
| 竖屏构图 | 人物是否以中近景/近景为主；大全景是否仅用于场次首镜建立空间；重要物件是否独立成镜特写；双人对话构图是否合理；过肩镜头是否慎用 | 第二十六节 |
| 钩子设计 | 开场第一镜是否冲突/情绪爆点/悬念/反转；结尾是否反转型/揭示型/冲突升级型/情绪定格型；是否拒绝慢热开场与平淡收尾 | 第二十六节 |

### 输出规范

- 所有分镜输出必须使用第十七节的固定模板
- 正向提示词必须以第一节通用质量基底开头，后接选定风格提示词
- 负向提示词必须包含：文字、字幕、水印、BGM、过曝、塑料皮肤
- 连续分镜之间必须明确标注空间关系继承
