## 四、人物站位与物理空间连续性

> **最重要的全局规则之一。**

### 空间锁定

每组连续分镜开始前，必须先明确：

- 人物之间的距离
- 朝向
- 左右位置
- 前后位置

**示例**：

陈洛与夏清月原本是：面对面、近距离对立站位、约一步距离。

那么后续镜头即使切换：近景 → 过肩 → 插入镜头 → 面部特写，也不能突然变成两人距离很远。

除非镜头明确表现：转身、后退、绕行、离开。

**人物空间变化必须有动作依据。**

### 连续性规则

- 上一镜人物在左，下一镜不要无理由突然跑到右。
- 上一镜面对面，下一镜不能突然变成并肩。
- 上一镜陈洛没有移动，下一镜不能突然站到很远。
- 人物绕行只能按照实际运动范围变化。
- 如果下一镜仍要求两人近距离对立，则上一镜结尾禁止：转身走开、后撤离场、彻底拉开距离。

### 空间锚点

复杂场景中要保留至少一个连续锚点：

- 人物肩膀
- 背影
- 玫瑰花海
- 掉落花束
- 门口
- 香案
- 建筑
- 围观学生

即使切特写，也要让观众知道人物仍处于同一个空间。

### 分镜间空间承接（强制规则）

> **每一分镜（除场次首镜外）必须显式书写"空间承接"段，承接自上一分镜，详细描述人物站位、人物动作等，以确保全程连贯。**
>
> 该字段写入固定分镜模板的"空间承接"项（详见第十七节），是分镜是否合规的硬性校验项（详见 `workflow.md` 校验清单）。

#### 必填五要素

每一分镜的"空间承接"必须明确以下五项，缺一不可：

1. **上一镜结尾状态**：上一镜最后一帧的人物站位、姿态、视线方向、空间锚点状态。
2. **本镜起始状态**：本镜第一帧如何承接上一镜结尾，标注承接类型（见下表）。
3. **人物站位承接**：本镜中每名人物的位置、朝向、与其他人物的相对关系（距离 / 左右 / 前后），与上一镜是否一致或如何变化。
4. **人物动作承接**：本镜人物肢体从上一镜的什么动作状态出发，进入什么动作状态；动作匹配（Match on Action）需明确指出衔接帧。
5. **空间锚点承接**：本镜保留哪些空间锚点（参考上文"空间锚点"清单），锚点状态如何延续（清晰 / 虚化 / 局部出现）。

#### 承接类型

| 承接类型 | 含义 | 适用场景 |
|----------|------|----------|
| 完全承接 | 站位、姿态、视线、锚点完全一致，仅景别 / 机位变化 | 同一动作连续推进，换景别拍摄 |
| 微调承接 | 站位不变，姿态 / 视线微调 | 情绪变化但空间未变 |
| 动作延续承接 | 上一镜动作的下一帧延续 | 动作匹配（Match on Action） |
| 视线承接 | 上一镜视线方向 → 本镜被看对象 | 视线匹配（Eyeline Match） |
| 位移承接 | 人物发生位移，需说明位移路径与终点 | 转身 / 后退 / 绕行 / 离场 |

#### 禁止项

- 禁止"上一镜在左、下一镜无理由跑到右"。
- 禁止"上一镜面对面、下一镜突然并肩"。
- 禁止"上一镜静止、下一镜已在远处"（无动作依据）。
- 禁止"上一镜结尾转身走开、下一镜仍近距离对立"。
- 禁止省略"空间承接"字段（场次首镜除外）。
- 禁止用"同上""承接上一镜"等模糊语代替详细描述。

#### 场次首镜特殊处理

每个场次的第一个镜头无需承接上一镜，但必须显式标注：

> **本镜为场次首镜，建立空间。**

并完整书写：场景空间结构（参考第十三节）、本镜起始站位、锚点初始状态。这是后续所有分镜空间承接的基准。

#### 示例

```text
【空间承接】
承接类型：完全承接
上一镜结尾状态：陈洛站在玫瑰花爱心左侧一步处，面朝夏清月，双手垂于身侧，视线锁定夏清月双眼；夏清月站在爱心右侧一步处，面朝陈洛，右手紧握书本至胸前，视线回避略偏左下。
本镜起始状态：完全承接，机位由中景切至过肩（机位绕至陈洛肩后看向夏清月），人物位置不变。
人物站位承接：陈洛仍处于爱心左侧一步处，与夏清月保持约一步距离，面对面，无位移；夏清月位置不变，仍是爱心右侧一步处。
人物动作承接：陈洛双手维持垂落姿态，右肩微前倾（承接上一镜身体前倾的提问动作）；夏清月右手仍紧握书本至胸前，下颌微收（承接上一镜视线回避的羞怯）。
空间锚点承接：玫瑰花爱心、围观学生仍在原位，处于虚化前景 / 背景；掉落花束仍在夏清月脚边，作为前景局部出现。
```

> 场次首镜示例：

```text
【空间承接】
本镜为场次首镜，建立空间。
场景空间结构：校园操场东侧，地面巨型玫瑰爱心已铺设完成，红气球环绕四周，约三十名大学生围成半圆围观；陈洛立于爱心左端一步处，夏清月立于爱心右端一步处，两人面对面，距离约一步。
本镜起始站位：陈洛面朝夏清月，双手垂于身侧；夏清月面朝陈洛，右手紧握书本至胸前。
空间锚点初始状态：玫瑰爱心清晰可见于画面下方；围观学生半圆站位作为背景虚化层；红气球作为前景局部点缀。
```
