# 固定分镜模板

> 此模板来自原 Skill 第十七节，使用时按需填写各项字段。

```text
【镜号】镜头标题 / 情绪功能

时长：
景别：
运镜：
角度：

空间承接：（承接自上一分镜，详细描述人物站位、人物动作等以确保全程连贯；场次首镜标注"本镜为场次首镜，建立空间"）

画面动作：

下意识细微动作：

全系声场：
台词情绪：
台词：
逻辑重音：
环境音：

人物与空间：

正向提示词：

负向提示词：
```

## 字段填写说明

| 字段 | 填写要求 | 对应规则 |
|------|----------|----------|
| 镜号 | 唯一编号，如 S01-A / S01-B（复杂段落用 A/B/C/D 拆分） | 第二节 |
| 镜头标题 / 情绪功能 | 一句话概括本镜动作与情绪功能。**若为他人反应镜头，须在标题后标注"【反应】"**（如：S03-B 夏清月反应【反应】/ 羞愧） | 第三节、第二十一节、第二十六节 |
| 时长 | 2-3s / 3-5s / 5-7s，按动作复杂度选择。**若为 9:16 短剧**：收紧至 1.5–4s，禁止超过 5s 静态长镜（情绪定格收尾镜除外）；A/B/C/D 拆分中 D 镜不超过 3s | 第二节、第二十六节 |
| 景别 | 全景 / 中景 / 中近景 / 近景 / 特写，按情绪浓度选择。**反应镜头（他人反应）景别须比当前对话镜更近一级**（如对话为中近景，反应切近景/特写），禁止同景别同机位跳切；反应镜仍须填写"空间承接"字段 | 第五节、第二十五节、第二十六节 |
| 运镜 | 慢推 / 环绕 / 手持 / 静止 / 焦点转移 / 插入镜头 | 第六节 |
| 角度 | 平视 / 俯视 / 仰视 / 倾斜，服务叙事与情绪 | 第二十五节 |
| 空间承接 | **必填**。承接自上一分镜，详细描述：上一镜结尾状态、本镜起始状态、承接类型、人物站位承接、人物动作承接、空间锚点承接（共五要素，详见第四节"分镜间空间承接"）。场次首镜标注"本镜为场次首镜，建立空间"，并书写场景空间结构、起始站位、锚点初始状态。禁止用"同上""承接上一镜"等模糊语代替详细描述 | 第四节、第十三节 |
| 画面动作 | 明确肢体动作 + 与物件的交互 | 第二十四节 |
| 下意识细微动作 | 微动作清单，匹配情绪浓度值（第二十二节微表情提示词） | 第七节、第二十二节 |
| 全系声场 | 对白 / OS / 动作音效 / 群杂 / 主观听觉（无 BGM、无字幕） | 第十六节 |
| 台词情绪 | 语速 + 音强 + 语调 + 情绪色彩（浓度值 %） | 第二十三节 |
| 台词 | 剧本原文，一字不增、不减、不改 | 第二十三节 |
| 逻辑重音 | 台词后括号标注，如（重音落在"远"） | 第十九节、第二十三节 |
| 环境音 | 场景环境音 / Foley / 主观听觉 | 第十六节 |
| 人物与空间 | 站位、距离、朝向、左右前后位置，与上一镜连续 | 第四节、第十三节 |
| 正向提示词 | 以第一节通用质量基底为基础 + 选定风格提示词 + 本镜具体描述 + 情绪浓度微表情 | 第一节、第十九节 |
| 负向提示词 | 文字、字幕、水印、BGM、过曝、塑料皮肤等禁止项 | 第一节、第十九节 |
