## 二十六、9:16 短剧导演思维

> 适用画幅：9:16 竖屏短剧。本节规则在第四节空间连续性、第五节景别衔接、第二节镜头拆分之上叠加，与之冲突时本节优先。

### 核心理念

9:16 竖屏短剧与传统横屏电影语言存在根本差异：

- **画幅限制**：垂直构图，水平空间被压缩，水平调度失效。
- **观看场景**：手机碎片化观看，注意力阈值低，3 秒不抓人即划走。
- **节奏要求**：信息密度高，每镜必推进剧情或情绪，拒绝留白与拖沓。
- **情绪密度**：情绪前置、情绪外显，微表情比台词更出戏。
- **反应优先**：观众看的是"听者的脸"，不是"说者的嘴"。

### 一、节奏紧凑规则

1. **单镜时长上限**：短剧每镜建议 **1.5–4s**，禁止超过 5s 的静态长镜（除非是情绪定格收尾镜，且必须配合明显情绪变化）。
2. **对话拆镜**：超过两句对话必须拆分 A/B 镜，每句重要台词独立成镜；一段对话不超过 3 句不切镜。
3. **信息前置**：每场戏前 3 秒必须给出钩子——冲突 / 悬念 / 反转 / 情绪爆点。拒绝慢热开场。
4. **拒绝铺垫**：能 1 镜说明的不用 2 镜，能 1 句台词说明的不用 2 句；铺垫信息融入动作中带出。
5. **钩子密度**：每 15–30 秒一个小钩子（小反转 / 新信息 / 情绪升级），每场戏结尾必留一个大钩子。
6. **A/B/C/D 拆分法收紧**：原 A/B/C/D 镜拆分在短剧中应进一步压缩，D 镜（情绪落点）时长不超过 3s。

### 二、长对话反应镜头规则（核心）

> **长对话（A 与 B 连续对话超过 3 句）必须插入他人反应镜头，否则节奏死亡。**

#### 插入时机

- **A 说完关键台词后**：切 B 反应镜头（0.5–1.5s），让"听者的脸"接管情绪。
- **A 说到一半**：切 B 微表情变化，捕捉"被击中"的瞬间。
- **重要潜台词出现时**：切对方眼神泄密（参考第九节双层表演）。
- **群像场景**：切围观者反应调节节奏，制造社会压力（参考第十节）。
- **台词停顿/换气处**：用反应镜头覆盖停顿，不留无声空白。

#### 插入景别

- 反应镜头建议 **近景 / 特写**，比当前对话镜头景别**更近一级**。
- 突出微表情区域：眼神、眼角、嘴角、下颌微动、喉结、手指。
- 禁止反应镜头与对话镜头同景别同机位——会变成跳切。

#### 插入频率

- 每超过 3 句连续对话，**必须至少插入 1 个反应镜头**。
- 情绪转折点、潜台词爆点、关键重音落点——**必切反应**。
- 不重要的过场台词，可用反应镜头覆盖原说话者（即画面是听者，声音是说者，L-CUT 处理）。
- 群像对话每 2–3 句切一次围观反应，避免主角脸审美疲劳。

#### 反应镜头的"空间承接"

反应镜头虽短，仍需遵守第四节"分镜间空间承接"规则：

- 承接类型一般为 **视线承接**（A 视线 → B 被看）或 **完全承接**（站位不变仅切景别）。
- 人物站位、空间锚点必须与上一镜一致。
- 即使 0.5s 的反应镜头，也要在"空间承接"字段中显式书写（可简写，但不可省略）。

### 三、竖屏构图规则

1. **人物构图以中近景 / 近景为主**（胸部以上），近景比例高于横屏。
2. **垂直空间利用**：头顶留白（情绪 / 压迫感）、脚下信息（站位 / 物件）、手部入画（动作）。
3. **双人对话构图**：
   - 上下构图：一人在上一人在下（适合同框对话）。
   - 前景后景虚化：一清晰一虚化，建立空间纵深。
   - 过肩镜头在竖屏中慎用——肩部会大量占用画幅。
4. **避免大全景**：竖屏全景信息过载，仅场次首镜建立空间时使用，且不超过 2s。
5. **物件特写独立成镜**：重要物件（手机、信件、戒指等）必须给独立特写镜头，禁止只靠中景带过。
6. **画面运动以垂直方向为主**：慢推可上下推，环绕慎用（水平空间不足）。

### 四、钩子设计规则

#### 开场钩子（前 3 秒）

- 每场戏第一镜必须是：冲突 / 情绪爆点 / 悬念 / 反转预告。
- 拒绝慢热开场、拒绝空镜铺垫。
- 可用**倒叙开场**：先放结果（如摔门、哭泣、对峙），再回到起因。
- 可用**特写开场**：以一个关键物件或人物特写直接进入情绪。

#### 结尾钩子（每场戏最后一镜）

- 每场戏最后一镜必留钩子，类型：
  - **反转型**：揭示一个出乎意料的信息。
  - **揭示型**：暴露一个被隐藏的关系或身份。
  - **冲突升级型**：新人物登场 / 新威胁出现。
  - **情绪定格型**：人物一个意味深长的表情收尾。
- 拒绝平淡收尾、拒绝"说完就走"。

#### 段落内小钩子

- 每 15–30 秒一个小钩子，避免长段平铺。
- 小钩子形式：新台词信息 / 人物微动作 / 反应镜头爆点 / 物件介入。

### 五、短剧表演与台词微调

- **台词短促**：能 1 句说完的不用 2 句，长独白拆成对话或 OS。
- **情绪前置**：第一句台词即带情绪色彩，不靠铺垫累积。
- **微表情密度提升**：竖屏近景放大脸部，微表情比横屏更重要，每镜至少 1 个微表情锚点。
- **OS 慎用**：OS 可补充内心，但短剧节奏快，OS 不超过 1 句且不超过 1.5s。

### 六、9:16 短剧导演思维校验清单

```text
【节奏校验】
□ 单镜时长是否超过 5s（超过需拆镜，除非情绪定格收尾）
□ 连续对话是否超过 3 句未切反应镜头
□ 每场戏前 3 秒是否有钩子
□ 段落内是否每 15–30 秒一个小钩子
□ 每场戏结尾是否留大钩子

【反应镜头校验】
□ 长对话是否插入他人反应镜头
□ 反应镜头景别是否比对话镜头更近一级
□ 反应镜头是否避免同景别同机位跳切
□ 反应镜头是否书写"空间承接"字段（可简写不可省略）
□ 群像对话是否每 2–3 句切一次围观反应

【竖屏构图校验】
□ 人物构图是否以中近景 / 近景为主
□ 大全景是否仅用于场次首镜建立空间
□ 重要物件是否独立成镜特写
□ 双人对话构图是否合理（上下 / 前后虚化）
□ 过肩镜头是否慎用

【钩子校验】
□ 开场第一镜是否冲突 / 情绪爆点 / 悬念 / 反转
□ 结尾是否反转型 / 揭示型 / 冲突升级型 / 情绪定格型
□ 是否拒绝慢热开场与平淡收尾
```

### 七、示例

> 长对话反应镜头示例（A 说三句后必切 B 反应）：

```text
S03-A：陈洛中近景，"你是不是从来没有爱过我？"（情绪：质问，浓度 75%）
S03-B：夏清月近景反应，下颌微收、视线回避（0.8s，情绪：羞愧，浓度 60%）
S03-C：陈洛中近景，"回答我！"（情绪：失控，浓度 85%）
S03-D：夏清月特写反应，眼眶泛红、嘴唇轻颤（1.2s，情绪：濒临崩溃，浓度 80%）
```

> 开场钩子示例：

```text
S01-A：夏清月特写，眼眶通红、紧攥离婚协议书（开场即情绪爆点，2s）
S01-B：拉至中景，陈洛背对镜头立于窗前（揭示对立关系，1.5s）
```
